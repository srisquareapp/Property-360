# PROPERTY 360

Mobile-first PWA for AP property verification.

Included:
- MeeBhoomi: 1-B / Adangal
- EC Search: Document / Survey
- LRS: Applicant search
- LRS / DTCP Dashboard: Completed layouts
- Property profiles
- Customer list
- LocalStorage data saving
- iPhone-friendly PWA shell

Government websites remain the authoritative source. This app opens them for the actual search and does not bypass CAPTCHA, OTP, login, or security controls.

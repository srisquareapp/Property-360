# PROPERTY 360 v3

Mobile-first AP property verification dashboard.

Services:
- MeeBhoomi — 1-B / Adangal
- EC — Document / Survey
- LRS — Applicant details
- Completed Layouts — LRS / DTCP dashboard
- Guntur Municipal Property Tax

Government portals are opened as official top-level browser pages. No CAPTCHA, OTP, login, or security control is bypassed.

On iPhone, if MeeBhoomi gives 403 in Safari but works in Chrome, use the Chrome fallback.

# PROPERTY 360

GitHub-ready mobile-first PWA prototype for AP property verification and real-estate CRM.

## Deploy on GitHub Pages
1. Create/open `srisquareapp/Property-360`.
2. Upload all files/folders from this project.
3. Repository Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Open the generated Pages URL on iPhone Safari and use Share → Add to Home Screen.

## Current behavior
- Property profiles and basic customer records are stored locally in the browser.
- Official MeeBhoomi, EC, LRS search and LRS/DTCP dashboard links open in a new tab.
- No CAPTCHA, OTP, login, or security control is bypassed.
- A backend/database and permitted direct integrations are required for cloud sync and automated result capture.
